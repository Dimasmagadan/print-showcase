# print-showcase

Публичная витрина 3D-печатных моделей: https://dimasmagadan.github.io/print-showcase/
Astro 7, статика, деплой GitHub Actions → Pages при push в `main`.
Модели берутся из соседнего репо `../3dprint` (только чтение, его не меняем).

## Договорённости

- Портфолио, без продажи и заказов. Кнопка «Связаться» — да.
- STL/3MF не отдаём, 3D-вьюер не ставим (из .glb модель легко вытащить).
- Код и рецепты моделей не показываем — только рассказ: «Идея / Как делал / Печать».
- Язык — русский. Своего домена нет.
- Что публиковать, выбирает пользователь. Не добавлять модели без его согласия.
- Тексты пишутся по README из `../3dprint/exports/<id>/`, но без внутренней кухни:
  «утверждено пользователем», имена файлов, команды сборки, замеры-пометки.
- Приватность: без имён и лиц детей, телефонов, номеров квартир/домов, подъездов.
  Фото только через скрипт импорта — он стирает EXIF (геометку).
- Новые тексты пользователь вычитывает до push.

## Как добавить модель

```bash
npm run import -- <model_id> [--extra <model_id>...] [--photos DIR]
```

Создаёт `src/content/models/<slug>/index.md` (draft: true) с рендерами и specs.
Повторный запуск с `--photos` докладывает фото и печатает YAML для `gallery`,
готовый текст не трогает. Размер считается по всем STL — если детали в экспорте
разложены для печати, а не собраны, поправить `specs.size` вручную.
`coverFit: contain` — для широких рендеров, которые обрезаются в карточке.
