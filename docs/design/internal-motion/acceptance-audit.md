# Аудит готовности

23 октября 2026. Полная готовность **не доказана**.

Исходное задание — вся `internal-motion-spec.md`, включая кадры,
реальные переходы, историю, доступность и браузерную матрицу.
Прохождение сборки или harness не заменяет визуальную приёмку.

Browser runtime во время трёх последовательных рабочих проходов возвращал
пустой список подключённых браузеров (`[]`). Последний запрос в текущем
проходе подтвердил то же состояние. Требуется подключить браузер через
Browser integration, чтобы получить оставшиеся доказательства и исправить
возможные визуальные/жизненные ошибки. Продолжать считать реализацию
принятой по одной сборке было бы неверно.

Последнее уточнение: h3 карточки → H1 страницы теперь отдельный общий элемент View Transition для каждой модели. Source/destination spans и одинаковый текст проверяет structural audit обеих сборок; runtime harness проверяет уникальные имена и cleanup каждой из шести моделей. Тестовый безусловный preview отключён, пороги/reduced motion/прерывания возвращены. Визуальная проверка движения текста и его переносов остаётся открытой.
