# Static visual review

These contact sheets are generated by `node scripts/robot-cat-playground-visual-review.mjs` from the delivered raster assets. They are separate from unit tests and browser screenshots.

- `assemblies.webp`: all twelve assembled combinations.
- `exploded.webp`: the corresponding connection views.
- `robot-to-cart-<head>-<body>.webp`: each head and body transition, with robot support leaving before the cart enters. `robot-to-cart.webp` is the cat/tail example.
- `head-swap-robot.webp` and `head-swap-cart.webp`: the cat-to-duck swap, including the attached beak.
- `wheel-phases.webp`: enlarged cart wheel phases; the muted marker is a render-only cue for rotation.

On the first review, three cart posters were visibly shifted and clipped. The renderer now resets every object's position before each poster, the assets were regenerated, and the raster test checks all poster bounds and the cart travel limits. The rabbit/tail, duck/tail and dog/plain transition sheets and both head-swap sheets were inspected after generation. Automated alpha-bound checks also cover every lift and connection frame at its scene zoom. The sheets do not verify browser layout, interaction, actual device gestures, or browser-wide memory usage.
