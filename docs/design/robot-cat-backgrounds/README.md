# Варианты динамического фона robot-cat

Локальные этюды, 2026-10-24. Оригинальная страница не менялась.

Dev server: http://127.0.0.1:4324/robot-cat-backgrounds/studio/#robot-key-0

- `studio`: тёплые медно-янтарные пятна света и крупные дуги.
- `aurora`: сине-фиолетовое сияние с бирюзовым светом.
- `blueprint`: сетка чертежа, медленный сдвиг и окружности.
- `orbits`: лиловый фон, вращающиеся орбиты и световые точки.

Маршруты доступны только в `astro dev`; production getStaticPaths возвращает пустой список.
Внизу каждой страницы переключатель вариантов, ссылка на оригинал и пауза фона.

Кадры имеют запечённую тёмную подложку: CSS `mix-blend-mode: lighten` пропускает фон через неё. Это приём для сравнения концепций: фон может немного проявляться в тёмных деталях модели. Для окончательного варианта можно экспортировать кадры с настоящей прозрачностью и тенями.
Фон продублирован внутри sticky stage, поскольку sticky создаёт отдельный контекст смешивания. Существующий runtime анимации и кадры не менялись.

Проверено в Chromium 1440×900: все четыре адреса, кадр 0, отсутствие горизонтального overflow. Для orbits дополнительно: прокрутка до кадра 84/K7, пауза обоих слоёв фона, мобильный 390×844, reduced motion. Сборка `npm run build` проходит, этюды не создают production HTML.
